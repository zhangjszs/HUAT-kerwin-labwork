# 智能网联汽车技术课程设计

本目录包含《智能网联汽车技术》课程设计的两个项目。

## 📁 目录结构

| 目录/文件 | 说明 |
|-----------|------|
| [fsd_presentation_website_html/](./fsd_presentation_website_html/) | FSD 智能驾驶演示网站（HTML） |
| [yolov7_plate_UI_camera/](./yolov7_plate_UI_camera/) | 基于 YOLOv7 的车牌识别系统 |

## 📝 项目说明

### FSD 智能驾驶演示网站

使用 HTML/CSS/JS 构建的自动驾驶技术演示网站，涵盖感知、规划、建图、仿真等模块。

### 基于 YOLOv7 的车牌识别系统

使用 YOLOv7 目标检测算法实现的车牌检测与识别系统，支持摄像头实时检测。

- **技术栈**: Python, PyTorch, YOLOv7, PyQt5
- **运行方式**: 参见 [yolov7_plate_UI_camera/README.md](./yolov7_plate_UI_camera/README.md)

## ⚠️ 注意事项

- 部分模型和权重文件通过 Git LFS 管理，克隆后请确保 LFS 文件已拉取
- `__pycache__/` 为 Python 缓存，无需关注
