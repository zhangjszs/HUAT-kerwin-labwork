## ⏱️ Countdown.asm —— 实验箱倒计时器

**功能**：从实验箱的 AD0809 采样电位器电压设定倒计时初值（约 10–200 秒），在 4 位数码管上动态扫描显示并倒计时。

**操作方式**（程序内置菜单）：

| 按键 | 作用 |
| ---- | ---- |
| `s` | 开始 / 恢复倒计时 |
| `p` | 暂停 |
| `Esc` | 取消，返回主菜单重新采样设定 |
| `q` | 退出程序 |

**技术要点**（行号以源码为准）：

- **8255 并行接口**：控制字 `81h` 初始化（方式 0）——A 口输出数码管段码，C 口高 4 位做数码管位选、低位读状态（L51 初始化、L138–152 位选与段码输出、L159–161 状态查询）。
- **8253 计数器 0 定时**：`delay` 子程序写入控制字 `20h` 与计数初值 `1194h`（=4500），产生约 4.5 ms 基准；`led_show` 以 74 次循环 × 3 次延时 ≈ 1 秒完成一次计数（L174–186、L134–155）。
- **AD0809 模数转换**：启动转换后查询 PC0 等待 EOC，读回结果并线性映射为秒数（`x = AD × 190 ÷ 255 + 10` → 10–200 秒）（L157–172）。
- **数码管动态扫描**：`process` 子程序把倒计数值分解为百/十/个位，经段码表 `ledb` 用 `xlat` 查表转换，3 位轮流点亮 + 第 4 位固定显示 `0`（L112–131、L43）。

> ⚠️ **端口基址必须先改**：文件首行注明"I/O 端口地址按实际连接加以修改"；端口常量集中在 L2 的 `ioport equ 0e080h-280h`，换一台实验箱必须按实际连接修改该行（8255 / 8253 / AD0809 的地址均由它派生）。

## 🎵 MusicPlay.asm —— 点歌系统

**功能**：菜单点歌，输入数字播放对应曲目；播放前后各显示一次当前时间（取自 CMOS 实时钟），输入 0 退出。

| 输入 | 曲目 |
| ---- | ---- |
| `1` | 两只老虎（two_tigers） |
| `2` | 一闪一闪亮晶晶（star） |
| `3` | 送别（songbie） |
| `0` | 退出系统 |

非法输入会提示 `input error! please input again:` 并要求重新输入（L227–252）。

**技术要点**（行号以源码为准）：

- **频率表 + 时值表驱动**：每首曲目由一张音高频率表（`mus_freq1`–`mus_freq3`，单位 Hz，如 262 / 294 / 330 对应 C4 / D4 / E4）与一张时值表（`mus_time1`–`mus_time3`）一一对应，表尾以 `-1` 标记结束（L28–108、L167–175）。
- **PC 扬声器发声**：`soundf` 子程序把 8253 定时器 2（端口 `43h` / `42h`，控制字 `B6h`）的计数值设为 1,193,100 ÷ 音符频率（源码 `dx:ax = 12348Ch`），再通过端口 `61h` 的 bit0/bit1 开关扬声器；每个音符后插入短停顿以区分（L260–300）。
- **`timer` 子程序读 CMOS 实时钟**：经端口 `70h` / `71h` 按单元号 9/8/7/4/2/0 读取年、月、日、时、分、秒，BCD 码转 ASCII 后显示在 `begin:` / `end  :` 行（L24、L371–418）。
- **BIOS 界面绘制**：`INT 10h` 定位光标与清屏，菜单背景色通过直接写文本模式显存 `B800h` 实现（L319–368、L204–208）。

> 注：源码顶部注释（L1–4）所写的曲名与实际菜单、频率表不符，实际曲目以上表（菜单字符串与数据表）为准；源文件按提交原貌存档，未作改动。

## 🛠️ 运行环境与复现说明

| 项目 | 要求 |
| ---- | ---- |
| 汇编器 | MASM 5.x / TASM（或实验箱配套的汇编调试软件） |
| 运行环境 | DOS 实模式（真机 DOS / Windows 9x 实模式，或 DOSBox 等模拟器） |
| 硬件（仅 Countdown） | 微机原理实验箱：8255、8253、AD0809 与数码管电路 |

通用汇编/链接步骤（两个程序相同，以 Countdown 为例）：

```text
masm Countdown.asm      ; 汇编生成 Countdown.obj
link Countdown.obj      ; 链接生成 Countdown.exe
Countdown.exe           ; 在 DOS 环境下运行
```

- `MusicPlay.asm` 只用 PC 扬声器与 BIOS/CMOS，可直接在 DOSBox 中运行（需在 DOSBox 配置中启用扬声器模拟）。
- `Countdown.asm` 依赖实验箱硬件，且必须先按实际连接修改 `ioport` 端口基址（见上节警告），否则无法正确访问 8255 / 8253 / AD0809。

> ⚠️ 上述步骤为通用做法整理，**未在本机实测**（仓库未附带汇编工具链与实验箱环境）。
